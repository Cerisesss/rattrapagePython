## Installation 
1. Cloner le projet :

```bash
git clone "projet_url"
```

2. Dataset
Verifier que le dataset (ventes.csv) est bien placé à la racine du projet. Si ce n'est pas le cas, veuillez le télécharger et le placer à la racine du projet.

3. Créer un environnement virtuel avec le terminal :
- Ouvrez le terminal et naviguez jusqu'au répertoire du projet. 
- Exécutez les commandes suivante pour créer et activer un environnement virtuel :

```bash
python -m venv .venv
source .venv/Scripts/activate
```

4. Installer les dépendances :

```bash
pip install -r requirements.txt
```

## Lancer le projet
- Utilisez la commande `python main.py` dans le terminal.
